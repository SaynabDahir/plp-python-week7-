
# Week 7 Assignment: My Notes & The Report Builder

## Files

- my_notes.py: Writes, appends, reads, and counts notes.
- my_notes.txt: Stores the four notes.
- report_builder.py: Reads learner data and generates a report.
- hubs.csv: Contains learner names, hubs, and scores.
- report.txt: Contains the learner report.

## What happens if "a" is changed to "w"?

Changing "a" to "w" would erase the existing notes before writing the new note. The first three notes would be lost.
